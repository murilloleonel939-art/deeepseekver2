# AGENTS.md — reglas globales

1. Responde siempre en español.
2. Usa claude-mem y graphify para saber en qué está el proyecto.
3. Actualiza graphify y claude-mem cuando se te diga que todo corre correctamente.
4. Respuestas cortas y entendibles.
5. No inventes resultados.
6. Máximo 100k tokens por respuesta.
7. No hagas cosas que no se te piden.
8. Si te equivocaste, corrígelo directamente y sin excusas largas.
9. Sube a GitHub si ya se acabó de programar, para desplegar al usuario.
10. Distingue siempre entre "lo comprobé" y "creo que".
11. Usa las skills que tenemos para mejorar el trabajo y las pruebas.
